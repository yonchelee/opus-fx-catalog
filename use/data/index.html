지도·데이터 시각화

지도, 지구본, 차트가 움직이며 숫자와 장소를 설명하는 효과입니다.

이런 곳에 씁니다

보고서 요약, 지역 소개, 성장 수치 같은 내용을 한눈에 보여 줄 때 씁니다. 내 데이터로 바꿔 넣을 수 있는지가 가장 중요합니다.

고를 때 확인할 것

  • 내 데이터(CSV·JSON)를 어디에 넣는지 프롬프트에서 알 수 있는지.
  • 지도 타일·지형 데이터처럼 외부 자료가 필요한지.
  • 숫자가 바뀌어도 축과 라벨이 깨지지 않는지.

필요한 실행 환경

HTML·SVG·Canvas, 경우에 따라 D3·지도 라이브러리. 영상으로 받으려면 렌더링 도구가 필요합니다.

편집자가 고른 작품 4개

  • 손그림 일본 폭염 지도연필 드로잉체 일본 지도에 폭염 데이터를 손글씨 다이어그램처럼 보여주는 3분 영상 · Claude Code · 적용 가이드 있음
  • SEO 백링크 네트워크 그래프사이트 노드들이 가중치 점수로 서로 연결되며 중요도가 전파되는 과정을 보여주는 다이어그램. · 채팅에서 바로 · 적용 가이드 있음
  • 광고 ROAS 대시보드 모핑광고 계정 연결부터 ROAS 차트까지 실제 UI 요소가 모핑하는 제품 프로모 영상 · Claude Code
  • 일상 지출 아이소메트릭 영상마트·주유소·식당 결제 장면을 아이소메트릭 3D로 보여주는 세로형 지출 시각화 영상 · Claude Code

키워드로 찾은 작품까지 더 보려면 갤러리에서 '지도·데이터 시각화' 모아 보기.
