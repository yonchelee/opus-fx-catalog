효과 갤러리

용도별로 찾기

어디에 쓸지 정해져 있다면 용도부터 고르세요. 각 페이지에 고를 때 확인할 것과 필요한 실행 환경을 정리했습니다.

  • 로고 애니메이션브랜드 로고나 글자 마크가 그려지고, 조립되고, 빛나며 등장하는 효과입니다. · 작품 4개
  • 웹사이트 배경·히어로 효과랜딩 페이지 첫 화면 뒤에서 움직이는 배경, 셰이더, 입자 효과입니다. · 작품 7개
  • 채팅에서 시작하는 효과설치 없이 Claude 채팅 화면의 미리보기(아티팩트)에서 바로 결과를 볼 수 있는 작품입니다. · 작품 9개
  • 제품·UI 소개 애니메이션앱 화면, 기능 흐름, 출시 소식을 보여 주는 제품 데모 영상과 인터랙션입니다. · 작품 8개
  • 지도·데이터 시각화지도, 지구본, 차트가 움직이며 숫자와 장소를 설명하는 효과입니다. · 작품 4개

모든 영상과 프롬프트의 권리는 각 원작자에게 있습니다. 미리보기는 원본 게시물의 공개 주소를 그대로 불러오며, 원본이 지워지면 보이지 않을 수 있습니다.
