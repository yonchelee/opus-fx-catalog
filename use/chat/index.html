채팅에서 시작하는 효과

설치 없이 Claude 채팅 화면의 미리보기(아티팩트)에서 바로 결과를 볼 수 있는 작품입니다.

이런 곳에 씁니다

처음 시도해 보기 좋은 작품을 모았습니다. 프롬프트를 붙여 넣으면 HTML 한 장이 만들어지고, 채팅 화면에서 바로 움직임을 확인할 수 있습니다. 결과는 원본과 다를 수 있으니 바꿀 변수를 함께 적어 요청하세요.

고를 때 확인할 것

  • 프롬프트가 전부 공개됐는지. 일부만 공개된 작품은 빈 부분을 직접 채워야 합니다.
  • 영상(MP4)으로 꼭 받아야 하는지. 채팅은 HTML 결과까지만 보여 줍니다.
  • 외부 이미지·폰트 같은 내 자료가 필요한지.

필요한 실행 환경

Claude 채팅(아티팩트 미리보기). 별도 설치 없음.
