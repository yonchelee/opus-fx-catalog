제품·UI 소개 애니메이션

앱 화면, 기능 흐름, 출시 소식을 보여 주는 제품 데모 영상과 인터랙션입니다.

이런 곳에 씁니다

기능 소개 페이지, 출시 공지, 발표 자료에 넣을 짧은 데모를 만들 때 참고합니다. 실제 내 제품 화면을 넣으려면 화면 캡처나 디자인 파일이 필요한 경우가 많습니다.

고를 때 확인할 것

  • 내 제품 화면(캡처·Figma)이 필요한지.
  • 영상으로 내보내야 하는지(Remotion 등 렌더링 도구 필요).
  • 문구와 화면 순서를 바꾸기 쉬운 구조인지.

필요한 실행 환경

웹으로 보면 HTML·CSS로 충분합니다. 영상 파일로 받으려면 Claude Code와 Remotion·Node.js 환경이 필요합니다.
