손그림 일본 폭염 지도

Japan's 2026 heat as a pencil-drawn data story

연필 드로잉체 일본 지도에 폭염 데이터를 손글씨 다이어그램처럼 보여주는 3분 영상

즐겨찾기는 이 브라우저에만 저장됩니다.

1어떤 효과인가

크림색 종이 질감 배경에 연필로 그린 일본 지도가 등장하고, 폭염 지역과 날짜가 빨간 동그라미와 손글씨 표로 하나씩 더해진다. 가벼운 색수차 효과로 아날로그한 인쇄물 느낌을 낸다.

2어디에 쓰면 좋은가

데이터 저널리즘 영상이나 기후·날씨 관련 소개 페이지의 설명 애니메이션으로 쓴다.

추천 이유: 연필 질감 일본 지도 위에 날짜·온도가 손글씨 다이어그램으로 겹쳐진 장면을 썸네일에서 확인했다.

3필요한 것

  • Claude Code 같은 개발 환경에서 파일을 만들어 실행
  • Claude Code
  • Node.js 또는 TypeScript
  • 웹 오디오(JavaScript 신시사이저)
  • 내 자료: 일본 폭염 관련 공개 데이터(연도별 비교 포함)

4실행 순서

  1. 보여줄 데이터 주제와 비교 연도를 정한다
  2. 관련 공개 데이터를 찾아 날짜·수치를 정리한다
  3. Claude Code에 손그림 펜화 스타일과 색수차 연출을 프롬프트로 전달한다
  4. JavaScript 신시사이저로 테마에 맞는 멜로디를 만들게 한다
  5. 지도와 데이터가 등장하는 순서를 3분 분량으로 구성한다
  6. 렌더링 후 손글씨 요소가 겹치거나 읽기 어려운 부분을 수정한다

5바꾸면 좋은 변수

지역과 데이터다른 나라·도시의 기후 데이터로 바꾼다
그림체연필 대신 수채화나 잉크 느낌으로 바꿀 수 있다
멜로디신시사이저 톤과 템포를 주제 분위기에 맞게 바꾼다

6원본 프롬프트

All right, this is an empty repo. Make me a 3-minute animated visualization using JavaScript, or you can do it in TypeScript if you want, about Japan's hot weather in 2026. Pull some online data to see why it was hot and how it compares to other years. I really want the animation to be visually appealing. I wanted to use a hand-drawn pencil style with a little bit of tasteful chromatic aberration. And maybe a bit of a pastiche look but it's supposed to look really, really cool. Also, use a JavaScript synthesizer to make a melody for this visualization that goes along with the theme.
