1어떤 효과인가

육각형 뱃지가 공중에 뜬 채 커서를 따라 물리적으로 기울어지고, 주변에 금빛 별 파티클이 떠다닌다. 해금 순간 빛이 퍼지며 축하 연출이 짧고 빠르게 재생된다.

2어디에 쓰면 좋은가

앱의 성취·레벨업·뱃지 수집 화면, 멤버십 등급 해금 화면에 쓰기 좋다.

추천 이유: 금테 육각 뱃지가 입체감 있게 떠 있고 별빛 파티클이 선명하게 보여, 앱 내 성취·보상 해금 화면에 바로 적용할 수 있는 완성도를 보여준다.

3필요한 것

  • Claude Code 같은 개발 환경에서 파일을 만들어 실행
  • Claude Code
  • Figma
  • Figma
  • 내 자료: 재현할 Figma 디자인 파일

4실행 순서

  1. 재현할 뱃지 디자인을 Figma 로 준비하거나 기존 틀을 그대로 쓴다
  2. Claude Code 에 Figma 프레임과 프롬프트를 함께 전달한다
  3. 생성된 코드를 저장하고 모바일 화면 비율로 확인한다
  4. 뱃지 모양과 금색 배색을 원하는 디자인으로 바꾼다
  5. 커서 추적 기울기 강도와 파티클 양을 조정한다

5바꾸면 좋은 변수

뱃지 디자인육각형 대신 원형·방패형 등 다른 모양으로 교체
컬러금색 톤을 브랜드 포인트 컬러로 변경
문구'Early Explorer' 같은 뱃지 이름과 설명 문구 교체

6원본 프롬프트

Using the linked Figma frame build a badge unlock screen. Match the design exactly. Use the file's assets, lighting, type and layout and add only the motion. Animate the badge so it feels premium and celebratory. Build its scene and then celebrate with gold particles. Treat the badge as a solid 3D object that tilts toward the
cursor following the rules of physics. Keep it fast and smooth, it should not be bouncy.

7적용용 요청문 만들기

아래 칸을 채우면 내 작업에 맞춘 요청문이 만들어집니다. 틀에 값을 채운 것이라 원본과 같은 결과를 보장하지 않습니다. 입력한 내용은 이 화면 밖으로 보내지 않습니다.
