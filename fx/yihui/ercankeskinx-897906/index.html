'올해의 컬러' 웹페이지

색상 스와치 카드가 펼쳐지는 화면 아래로 전혀 다른 톤의 섹션이 이어지는 스크롤 웹페이지.

채팅에서 바로프롬프트 전체 공개미검증

즐겨찾기는 이 브라우저에만 저장됩니다.

1어떤 효과인가

크림색 배경 위에 '올해의 컬러' 문구와 여러 색상 스와치 카드가 비스듬히 펼쳐진 화면이 먼저 보이고, 스크롤하면 어두운 톤의 다음 섹션으로 전환된다. 섹션마다 레이아웃과 분위기가 완전히 다르다.

2어디에 쓰면 좋은가

에이전시 포트폴리오나 랜딩 페이지에서 섹션별로 톤을 바꿔가며 보여주고 싶을 때 쓰기 좋다.

추천 이유: 크림 배경에 색상 스와치 카드가 비스듬히 펼쳐지는 장면과 그 아래 전혀 다른 톤의 섹션이 이어지는 구성이 썸네일에서 뚜렷해, 짧은 지시만으로 다양한 섹션 레이아웃을 뽑아내는 참고가 된다.

3필요한 것

  • Claude 채팅 미리보기에서 바로 볼 수 있음
  • Claude 채팅
  • Claude Code

4실행 순서

  1. Claude 채팅에 원본 프롬프트를 붙여 넣는다
  2. 생성된 섹션들을 끝까지 스크롤하며 구성을 확인한다
  3. 마음에 드는 섹션만 골라 코드를 따로 뗀다
  4. 색상·문구·이미지를 실제 브랜드 소재로 바꾼다
  5. 섹션 순서와 전환 효과를 다듬는다

5바꾸면 좋은 변수

섹션 주제색상 스와치 대신 제품·서비스 소개 등으로 소재 교체
색상 팔레트크림톤 배경을 브랜드 색으로 교체
문구'Frost Chalk' 같은 샘플 문구를 실제 카피로 교체

6원본 프롬프트

Build 5 completely different scroll-based sections, decide the context & layout yourself.
