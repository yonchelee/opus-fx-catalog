반 고흐 그림 속 고양이 찾기

별이 빛나는 밤 화풍 그대로 걸어 다니며 숨은 고양이를 찾는 3D 탐험 게임

채팅에서 바로프롬프트 전체 공개미검증
미리보기를 불러오지 못했습니다.원본 게시물에서 보기
갤러리에서 보기

즐겨찾기는 이 브라우저에만 저장됩니다.

1어떤 효과인가

반 고흐 '별이 빛나는 밤' 화풍을 그대로 입힌 마을을 3D로 걸어 다니며 숨은 고양이를 찾는 탐험 게임이다. 하늘은 소용돌이치는 붓터치로 움직인다.

2어디에 쓰면 좋은가

미술관·전시 체험 코너, 교육용 인터랙티브 콘텐츠, 브랜드 이벤트 미니게임에 어울린다.

추천 이유: 고흐 특유의 소용돌이 붓터치가 3D 공간에 그대로 유지된 모습이 썸네일에서 확인되고, 한 줄 프롬프트로 시작했다는 점이 바로 따라하기 좋다.

3필요한 것

  • Claude 채팅 미리보기에서 바로 볼 수 있음
  • Claude 채팅
  • Three.js

4실행 순서

  1. Claude 채팅에 원본 프롬프트를 붙여 넣는다
  2. 다른 명화(예: 뭉크, 클림트)로 화풍을 바꿔 달라고 요청한다
  3. 찾을 대상을 고양이 대신 다른 캐릭터로 바꾼다
  4. 조작 방식(걷기/날기)과 카메라 시점을 조정해 달라고 요청한다
  5. 결과를 보고 화풍 유지 디테일을 추가로 다듬는다

5바꾸면 좋은 변수

명화반 고흐 대신 다른 화가의 그림으로 바꿀 수 있다
찾을 대상고양이 대신 다른 오브젝트나 캐릭터로 바꿀 수 있다
월드 범위마을 외에 다른 장면(밀밭, 카페 테라스 등)으로 확장할 수 있다

6원본 프롬프트

can you make a 3d game where you walk around and spot cats inside of a van gogh painting? we can start with stary night and its town

7적용용 요청문 만들기

아래 칸을 채우면 내 작업에 맞춘 요청문이 만들어집니다. 틀에 값을 채운 것이라 원본과 같은 결과를 보장하지 않습니다. 입력한 내용은 이 화면 밖으로 보내지 않습니다.
