저폴리 조각 로고 리빌

Low-poly shard logo reveal

와이어프레임에서 저폴리 조각이 모여 앱 로고가 완성되는 슬로우 리빌 영상

채팅에서 바로프롬프트 전체 공개미검증
미리보기를 불러오지 못했습니다.원본 게시물에서 보기
갤러리에서 보기

즐겨찾기는 이 브라우저에만 저장됩니다.

1어떤 효과인가

어두운 배경에서 로고가 먼저 와이어프레임 선으로 그려지고, 각진 저폴리 조각들이 하나씩 날아와 자리를 잡으며 로고를 완성한다. 마지막에 앱 아이콘 배경색이 채워지고 브랜드명이 타이핑되듯 나타난다.

2어디에 쓰면 좋은가

앱 소개 영상이나 런칭 영상의 도입부, 브랜드 인트로 장면에 쓴다.

추천 이유: 와이어프레임 조각이 모여 보라색 앱 아이콘(P)으로 완성되는 장면을 실제 영상 프레임에서 확인했다.

3필요한 것

  • Claude 채팅 미리보기에서 바로 볼 수 있음
  • Claude 채팅 또는 Claude Code

4실행 순서

  1. 완성된 로고 이미지와 브랜드명을 준비한다
  2. Claude 채팅이나 Claude Code에 로고 리빌 프롬프트를 전달한다
  3. 와이어프레임으로 먼저 그려지는 단계를 확인한다
  4. 저폴리 조각이 조립되는 순서와 속도를 점검한다
  5. 앱 아이콘 배경색과 브랜드명 타이핑 타이밍을 맞춘다

5바꾸면 좋은 변수

로고 모양다른 로고나 아이콘 이미지로 교체한다
배경색과 조각 색브랜드 컬러에 맞춰 바꾼다
브랜드명 텍스트타이핑되는 문구를 바꾼다

6원본 프롬프트

Create a motion design video of a slow-reveal transition. Draw the logo as a wireframe first, then fly in faceted low-poly shards one by one until they assemble the logo. Finish by bringing in the app icon background and typing out the brand name.
