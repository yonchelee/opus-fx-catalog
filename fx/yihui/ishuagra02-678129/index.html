파티클로 그린 해변 러너

Particle-illustration Santa Monica beach

수천 개 빛 입자로 그린 산타모니카 해변, 달리는 인물 뒤로 리본 궤적이 흐른다

채팅에서 바로프롬프트 전체 공개일부 확인
미리보기를 불러오지 못했습니다.원본 게시물에서 보기
갤러리에서 보기

즐겨찾기는 이 브라우저에만 저장됩니다.

1어떤 효과인가

해 질 녘 산타모니카 해변을 수천 개의 빛나는 점으로 그린 3D 장면이다. 인물이 달리면 몸 뒤로 흐르는 리본 모양 궤적이 남고, 배경에는 놀이공원 관람차와 롤러코스터 실루엣이 보인다.

2어디에 쓰면 좋은가

제품 소개나 포트폴리오 랜딩 첫 화면, 감성적인 인트로 배경에 어울린다.

추천 이유: 보드워크 디테일과 반짝이는 입자 질감, 움직임을 암시하는 리본 획이 썸네일에서 그대로 확인된다.

3필요한 것

  • Claude 채팅 미리보기에서 바로 볼 수 있음
  • Claude 채팅
  • Three.js
  • GLSL 셰이더

4실행 순서

  1. Claude 채팅에 원본 프롬프트를 붙여 넣는다
  2. 해변 대신 원하는 장소로 배경을 바꿔 지시한다
  3. 입자 밀도와 리본 궤적 굵기를 조정해 달라고 요청한다
  4. 시간대(낮/노을/밤) 전환 연출을 추가로 요청한다
  5. 결과를 보고 2~3차례 더 다듬어 달라고 후속 프롬프트를 보낸다

5바꾸면 좋은 변수

장소해변 대신 도시 거리나 숲 등으로 바꿀 수 있다
시간대낮/노을/밤 조명을 바꿔 분위기를 조절한다
입자 밀도점 개수를 늘리거나 줄여 질감을 조절한다

6원본 프롬프트

Create a stylistic 3D environment of a busy Santa Monica beach that adapts to the time of day. The art style must be a particle illustration, which uses thousands of tiny glowing specks rather than solid fills with flowing ribbon strokes behind figures to suggest motion.

I had 2-3 more prompts on top of this, but this is a good starting point.

Repo link: https://github.com/ishuagrawal/particle-beach

8출처와 검증

  • 원작자 @ishuagra02 · 원본 게시물 · 프롬프트 출처
  • 검증: 일부 확인 — 수만 개의 빛나는 입자로 모래·바다를 그리는 기법은 같게 나왔습니다. 원본의 인물 리본 궤적, 피어·관람차 같은 해변 구성, 해 질 녘 빛 연출은 나오지 않았습니다. (2026-10-10, Claude Code 세션에서 원본 프롬프트로 HTML 한 장을 만들어 헤드리스 Chrome에서 렌더링 (claude.ai 채팅 미리보기 아님)) · 만들어 본 결과 화면
  • 원본 X 게시물 좋아요 18 — 이 사이트의 평가가 아닙니다.
  • 영상·프롬프트의 권리는 원작자에게 있습니다. 작품 ID yihui:ishuagra02-678129 · 수집 2026-09-26

같은 용도의 다른 작품

  • 저폴리 조각 로고 리빌와이어프레임에서 저폴리 조각이 모여 앱 로고가 완성되는 슬로우 리빌 영상
  • e바이크 엑스레이 제품 히어로마우스로 외관을 지우면 내부 구조가 드러나는 커서 추적 엑스레이 제품 히어로 섹션
  • 반 고흐 그림 속 고양이 찾기별이 빛나는 밤 화풍 그대로 걸어 다니며 숨은 고양이를 찾는 3D 탐험 게임
  • 뒤집힌 피라미드 초현실 월드거대한 역피라미드 건축물에서 폭포가 쏟아지는, 자유 탐험용 초현실 3D 세계

모든 영상과 프롬프트의 권리는 각 원작자에게 있습니다. 미리보기는 원본 게시물의 공개 주소를 그대로 불러오며, 원본이 지워지면 보이지 않을 수 있습니다.
