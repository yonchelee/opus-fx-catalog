How SEO backlinks work, visualized

사이트 노드들이 가중치 점수로 서로 연결되며 중요도가 전파되는 과정을 보여주는 다이어그램.

즐겨찾기는 이 브라우저에만 저장됩니다.

1어떤 효과인가

어두운 배경 위에 웹사이트를 뜻하는 원형 노드들이 화살표로 연결되고, 링크를 받을수록 노드가 커지며 점수가 올라간다. 반복마다 값이 수렴하는 과정이 단계 제목과 함께 보여진다.

2어디에 쓰면 좋은가

SEO·데이터 분석 서비스 소개 페이지나 알고리즘 설명용 블로그 포스트 삽입 영상에 쓰기 좋다.

추천 이유: 노드 크기와 화살표 색으로 링크 가중치가 전파되는 과정을 단계별로 보여주는 장면이 썸네일에서 선명해, 설명하기 어려운 알고리즘을 시각적으로 풀어내는 참고 사례로 적합하다.

3필요한 것

  • Claude 채팅 미리보기에서 바로 볼 수 있음
  • Claude 채팅
  • Claude Code
  • Canvas

4실행 순서

  1. Claude 채팅이나 Claude Code 에 프롬프트를 붙여 넣는다
  2. 생성된 단일 HTML 을 저장하고 브라우저로 연다
  3. 노드 배치와 애니메이션 속도를 확인한다
  4. 노드 이름과 점수를 실제 데이터나 다른 주제로 바꾼다
  5. 색상 팔레트를 브랜드 톤에 맞춰 조정한다

5바꾸면 좋은 변수

노드 데이터사이트 이름과 점수 값을 실제 분석 데이터로 교체
색상강조 노드 색(주황)을 브랜드 포인트 컬러로 변경
반복 횟수수렴 단계 수를 늘리거나 줄여 속도 조정

7적용용 요청문 만들기

아래 칸을 채우면 내 작업에 맞춘 요청문이 만들어집니다. 틀에 값을 채운 것이라 원본과 같은 결과를 보장하지 않습니다. 입력한 내용은 이 화면 밖으로 보내지 않습니다.

다음 효과를 참고해서 내 용도에 맞게 새로 만들어 주세요.

[참고한 효과]
원형 노드들을 화살표로 연결해 값이 한쪽에서 다른 쪽으로 흘러가며 노드 크기가 점점 변하는 네트워크 다이어그램이다. 매 반복마다 값이 수렴해 가는 과정을 단계 제목과 함께 보여주고, 강조할 노드는 색을 다르게 표시한다. 복잡한 알고리즘이나 관계망을 한눈에 설명할 때 쓰는 연출로, 구체적 스타일 지시 없이도 모델이 레이아웃과 색감을 알아서 구성하게 둘 수 있다.

8출처와 검증

  • 원작자 @stewchan2 · 원본 게시물 · 프롬프트 출처
  • 검증: 일부 확인 — 어두운 배경에서 내 사이트 노드로 백링크가 모이는 네트워크 구조는 같게 나왔습니다. 원본의 영화 같은 전개(문구 → 카메라가 멀어지며 점이 이어짐)와 타이틀 카드는 나오지 않았고, 정적인 인포그래픽에 가까웠습니다. (2026-10-10, Claude Code 세션에서 원본 프롬프트로 HTML 한 장을 만들어 헤드리스 Chrome에서 렌더링 (claude.ai 채팅 미리보기 아님)) · 만들어 본 결과 화면
  • 원본 X 게시물 좋아요 1 — 이 사이트의 평가가 아닙니다.
